# Development workflow

An agent skill for coordinating software development from the requested outcome to evidence of completion.

Start with [SKILL.md](SKILL.md). It routes investigations, reviews, bug fixes, features, and refactoring to focused playbooks in [`references/`](references/), with additional guidance for verification and performance evidence.

The workflow emphasizes bounded plans, preserving existing work, explicit permission boundaries, observable delegation, and evidence-backed handoffs.
